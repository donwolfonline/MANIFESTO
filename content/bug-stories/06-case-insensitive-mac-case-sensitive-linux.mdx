The branch built cleanly on my laptop, every component rendered crisply on localhost, and I pushed with full confidence twenty minutes before a review.

## What went wrong

The Linux deployment container immediately halted with 'Cannot find module ./SummaryCard'. I stared at my sidebar where the file was sitting right there in plain sight—spelled with a lowercase 's' that APFS had kindly forgiven and Git had never renamed.

## The lasting change

Enabling TypeScript's consistent-casing compiler check and using `git mv` for capitalization changes closed that trap permanently.
