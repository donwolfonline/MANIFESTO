Shipping is not merging the happy path while leaving three dead feature flags, a commented-out debug route, and a stale migration file scattered behind you.

- Delete the temporary rollout toggle once traffic sits at 100%.
- Check the error copy and empty state before closing the ticket.
- Retire the stray branches—a finished room looks calm once the tools are put away.
